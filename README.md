# Arxy

Public documentation repository for **Arxy Discord bots**.

This repository contains the official, user-facing documents and public pages for Arxy projects. Internal source code, credentials, private infrastructure details, experimental systems, and non-public projects are intentionally kept out of this repository.

## Armoni

**Armoni** is a Discord bot focused on private voice-room management. It provides a structured flow for creating and managing private voice channels, room ownership, access controls, and panel-based room actions.

### Public documents

- [Official documents page](./armoni/index.html)
- [Privacy Policy](./armoni/privacy.html)
- [Terms of Service](./armoni/terms.html)

## Repository scope

This repository is intended for:

- public legal and policy documents
- official user-facing information
- public project links
- documentation required for Discord integrations

It is **not** intended to publish private source code, authentication data, infrastructure configuration, credentials, or internal development material.

## Security

No API keys, bot tokens, passwords, private endpoints, or other secrets should be committed to this repository.

For support, installation questions, or data-related requests, use the official support link listed on the Armoni documents page.
