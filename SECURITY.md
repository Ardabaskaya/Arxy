# Security Policy

## Public repository scope

This repository contains public documentation for Arxy projects. It must not contain credentials, private infrastructure details, internal configuration, or non-public project material.

## Do not commit

- Discord bot tokens
- API keys or access tokens
- passwords or private keys
- database credentials
- private endpoints or internal configuration
- personal or confidential user data

## Reporting

If you discover a security or privacy issue related to Arxy or Armoni, please use the official support channel linked from the [Armoni documents page](./armoni/index.html).

Please avoid publishing sensitive details in a public GitHub issue.
